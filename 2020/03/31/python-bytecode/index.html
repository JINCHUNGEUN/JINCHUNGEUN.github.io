翻译自Understanding Python Bytecode

Python语言属于解释性语言，不像编译型语言，等程序完成后一次性编译成可执行的文件，而是边写边编译，虽然影响了执行速度，但是可以马上看到效果。

每当运行.py文件，Python首先编译源码到字节码(bytecode)，这不是二进制的机器语言 也不能直接运行，它是一系列的指令，可以在PVM(Python Virtual Machine)执行，PVM会读取字节码并编译到最终的机器语言。官方提供的默认解释器是Cpython，是用C语言实现的，Cpython会把python源码编译到特定的字节码，字节码会被
其他的解释包括：

  • Pypy：使用JIT技术，静态编译而不是解释，所以大大提高的执行速度
  • Jython：使用java实现的解释器
  • IronPython：使用.net实现的解释器

1. 生成字节码

字节码是存储在.pyc后缀的文件里，Python程序运行后 在项目的各个目录底下根据需求自动生成__pycache__文件夹，文件夹底下会有很多.pyc文件。
